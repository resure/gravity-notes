## Default Permission

Allows picking an iOS folder, resolving its saved bookmark, and coordinated per-note read/write.

#### This default permission set includes the following:

- `allow-pick-folder`
- `allow-resolve-bookmark`
- `allow-read-note`
- `allow-write-note`
