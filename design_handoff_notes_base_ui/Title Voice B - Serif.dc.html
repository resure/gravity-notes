Migration — GravityUI → Base UI

Edited 18:20 · Work / Projects / Alpha

We are moving the whole surface off GravityUI. The editor stays where it is; what changes is every piece of chrome around it — menus, popovers, the settings dialog, the sort control, toggles.

What we keep

The three-pane shell, the block editor, per-note appearance overrides and the linked-references footer.
